# Competitive Programming Prep

A personal repository documenting my journey in Competitive Programming. This repository contains solutions, notes, templates, and practice from various online judges with the goal of improving problem-solving skills and contest performance.

## Goals

- Reach Expert-Master level on Codeforces.
- Build strong algorithmic thinking.
- Prepare for ICPC, internships, and coding interviews.
- Maintain a well-organized archive of solved problems.

## Platforms

- Codeforces
- LeetCode
- HackerEarth
- CSES
